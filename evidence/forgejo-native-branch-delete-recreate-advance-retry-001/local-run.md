# FORGEJO-NATIVE-BRANCH-DELETE-RECREATE-ADVANCE-RETRY-001

Date : 26 octobre 2026. Ce run renforce le parcours de réconciliation après disparition temporaire : Forgejo émet les événements natifs `create` et `delete`, le readback après suppression donne `inconclusive/resource_not_found`, puis le hook est désactivé et sa désactivation relue. Avant de recréer la même branche, le runner ajoute un nouveau commit à la tête locale. Le push recrée la ref au SHA `622b6ef3103fc6789ca209fafe26ebb2fac7109e`, différent de la tête `3bdfd0a27ce60d8e8de92eba5fe9b9a3a7fd9e12` qui avait existé avant la suppression.

Le compte read-only confirme le nouveau SHA. Une invocation neuve du CLI réconcilie les deux IDs Forgejo d’origine, dans leur ordre, vers ce nouveau commit : les deux résultats sont `current_state_read/present`. Le runner compare l’inbox byte-à-byte sur les tentatives et relit les tâches Forgejo SQLite : les deux tâches create/delete d’origine avec HTTP 202 restent seules, aucune nouvelle livraison ne se produit pendant la recréation. Le reçu est dans [live-run](live-run/result.json), avec un vérificateur des assertions et du manifeste dans [verify_advance_retry.py](verify_advance_retry.py).
