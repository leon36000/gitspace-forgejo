# MERGE-016 local fixtures

The key in `fixtures/fixture-verifier.key` is deliberately public test data and must never be reused outside this isolated fixture. The evidence and target values are synthetic. These fixtures validate CLI parsing and V1/V2 signing; they are not test results, do not refer to a real commit, and do not authorize any Forgejo merge.

MERGE-016 keeps V1 verification unchanged and makes the local merge authority require a strict target-bound V2 proof. The V2 MAC covers all five canonical target fields plus evidence. V2 signing and verification reject keys shorter than 32 bytes; the authority returns an actionable `invalid_verifier_key` with `minimum_bytes=32`. This is a length floor, not evidence of key entropy or safe provisioning. File ownership and mode `0600` do not isolate a verifier from an agent sharing its UID or access to the key.
